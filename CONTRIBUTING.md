# Contributing to Octoquery

Thanks for your interest in contributing!  
Octoquery is a personal learning project, but contributions are still welcome.

## Ways to Contribute

- Report bugs
- Suggest new features or improvements
- Submit pull requests

## Development Setup

Please follow the instructions in the [README](README.md) to set up the project locally (or use the provided Dev Container).

## Code Style

- This project uses **Biome** for linting and formatting.
- Please run the formatter before committing:

```bash
pnpm biome check --write .
```

- Keep TypeScript types as strict as possible.
- Prefer clear and simple code over clever solutions.

## Pull Request Process

1. Fork the repository and create a new branch from `main`.
2. Make your changes.
3. Make sure the code passes linting and TypeScript checks.
4. Open a pull request and briefly describe what you changed and why.

## Questions?

Feel free to open an issue if you have any questions before contributing.
